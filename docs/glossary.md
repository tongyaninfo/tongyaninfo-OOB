# 关键术语

本文解释项目中容易混淆的术语；接口字段与枚举以[接口合同](api/README.md)及源码为准。

| 术语 | 本仓库含义 | 不能推断成 |
| --- | --- | --- |
| OOB / 带外管理 | 通过服务器独立管理通道（BMC）管理硬件，不依赖操作系统 | 操作系统内的远程管理工具 |
| BMC | Baseboard Management Controller，服务器带外管理控制器 | 操作系统内的服务 |
| iLO4 | HP 服务器带外控制器（当前支持的型号之一） | 所有 HP 服务器或新版本 iLO |
| iDRAC 8 | Dell 服务器带外控制器（当前支持的型号之一） | 所有 Dell 服务器或新版本 iDRAC |
| Redfish | DMTF 的 REST 式带外管理标准 | 所有固件版本能力一致 |
| 库存（Inventory） | 从设备读取并保存的硬件清单（CPU、内存、磁盘、控制器等） | 实时读数 |
| 遥测 / 采样 | 按采样间隔读取的传感器与功率读数，写入时序表 | 对外上报的遥测数据 |
| 缺测 | 设备未提供或本次未取得读数，保留为 null | 读数等于 0 |
| 过期 | 读数时间超出有效期，界面明确标记 | 数据被删除 |
| 虚拟控制台 | 通过浏览器访问的设备 KVM 画面与输入通道 | 操作系统远程桌面 |
| 虚拟介质 | 把本地 ISO、URL 或镜像库镜像映射为设备光驱 | 上传文件到设备存储 |
| UID | 服务器机箱定位指示灯（Unit ID） | 用户标识 |
| MCP | Model Context Protocol，外部 AI 客户端访问只读查询工具的协议 | 大模型服务本身 |
| OAuth / PKCE | MCP 远程访问的授权协议与客户端校验方式 | 浏览器 Cookie 登录 |
| 采集器（Collector） | 后台单实例有界任务，负责按计划读取设备数据 | 多副本分布式采集 |
| 电源操作意图 | 记录用户电源动作请求与结果的审计对象 | 直接保证设备已执行 |
| 结果未知 | 请求可能已执行，需按原请求核对设备状态 | 请求失败，可以重试 |
| 运行报表 | 按日/周/月统计并生成 HTML 的运行报告 | 实时监控画面 |
| ApiResult | 后端统一响应信封，保留对应 HTTP 状态码 | 仅 HTTP 200 的包装 |
| 合同（Contract） | 本文档语境中的 API schema、路由和生成类型 | 商业合同单据 |
| 已实现 / 已验证 / 已验收 | 分别指存在实现、某次检查通过、责任方接受结果 | 三者可互相替代 |

长 ID 在 JSON 中以字符串传输；时间存 UTC，展示默认 Asia/Shanghai，只转换一次。完整约定见 [AGENTS](../AGENTS.md) 与[架构地图](architecture.md)。
