# 1.0.4 版本说明

- 日期：2026-11-05
- 数据库目标与 1.0.3 一致（postgresqlBusiness 10 个、postgresqlOAuth 1 个、sqlite 4 个迁移）
- 无新增迁移与数据库结构变化

修复桌面发布流水线在 macOS Intel 平台上的超时问题：

- macOS Intel runner 构建并上传安装包耗时超过原 45 分钟限制，导致任务在「上传安装包」
  步骤被取消、发布门禁未通过；将桌面任务超时提高到 90 分钟。
- 上一版已完成的修复继续生效：Windows 模板行尾、Linux deb maintainer、macOS 上传路径收窄、
  PC 前端集中构建（含 Windows ARM64）。

升级兼容 1.0.0–1.0.3；数据库结构相同，无需额外迁移。
