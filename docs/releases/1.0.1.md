# 1.0.1 版本说明

- 日期：2026-11-04
- 数据库目标：与 1.0.0 一致（postgresqlBusiness 10 个、postgresqlOAuth 1 个、sqlite 4 个迁移）
- 本版无新增迁移与数据库结构变化

本版修复 Windows 构建环境中可执行文件行尾被自动转换为 CRLF 导致前端构建许可校验误报的问题：

- 构建工具包的 LICENSE 通过 `.gitattributes` 固定以 LF 检出；
- 前端构建依赖检查按规范化行尾读取许可正文，Windows 本地检出也能通过。

升级兼容 1.0.0；数据库结构与 1.0.0 相同，无需额外迁移。
