# 1.0.2 版本说明

- 日期：2026-11-05
- 数据库目标与 1.0.1 一致（postgresqlBusiness 10 个、postgresqlOAuth 1 个、sqlite 4 个迁移）
- 无新增迁移与数据库结构变化

修复跨平台桌面安装包构建中的三处平台差异：

- Windows：离线模板资源（SVG）由 Windows 检出时被转换为 CRLF，导致摘要校验失败；
  通过 `.gitattributes` 固定行尾，并在校验时按规范化文本计算摘要。
- Linux：deb 打包缺少 maintainer 信息，补充到 electron-builder 的 linux 配置。
- macOS：安装包上传改为只上传安装文件，避免 `.app` 目录触发 artifact 上传内存溢出。

升级兼容 1.0.0 / 1.0.1；数据库结构相同，无需额外迁移。
