# 1.0.3 版本说明

- 日期：2026-11-05
- 数据库目标与 1.0.2 一致（postgresqlBusiness 10 个、postgresqlOAuth 1 个、sqlite 4 个迁移）
- 无新增迁移与数据库结构变化

调整桌面发布流水线的前端构建方式：

- PC 前端改由独立的 frontend job 在 Linux x64 上集中构建，产物打为 tar 分发给各平台；
- 各桌面 job 使用 `--skip-frontend-build` 复用该产物，避免在 Windows ARM64 等平台安装
  Umi/utoo 原生绑定（`@utoo/pack-win32-arm64-msvc` 上游未发布）。
- 桌面安装包仍为未签名测试包：macOS 使用 ad-hoc 签名，Windows 未签名。

升级兼容 1.0.0 / 1.0.1 / 1.0.2；数据库结构相同，无需额外迁移。
