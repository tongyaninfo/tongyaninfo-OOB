- 产品版本：`1.0.0`，根 [VERSION](../../VERSION) 为唯一来源；口语“1.0”从本次起规范为三段产品版本。
- 基线日期：2026-11-03。
- 关联：开源首发版本，基于 1.0.0 源码基线。
- 状态：建立源码与迁移目标基线；本仓库不包含制品打包、镜像推送、环境迁移与人工发布验收记录。
- 依据：[版本规约](README.md)、[ADR-0013](../adr/ADR-0013-产品版本与数据库升级追溯.md)。

## 范围与兼容性

封存当前服务端 .NET/PC 与桌面 Electron/SQLite 的共同产品版本。现有功能入口见[仓库说明](../../README.md)，不因封版新增业务能力、修改 API 合同或重新执行历史迁移。

本次代码只建立版本来源、构建产物版本信息和静态迁移追溯门禁；数据库新结构/数据变换为**无**，新增 EF 迁移为**无**，引擎/扩展升级为**无**。下表是当前源码已经包含的完整历史目标，必须与真实环境分开核对。

PC 的 `frontend/PC/package.json` `6.0.3` 保留模板来源含义，产品展示/构建读取 `VERSION`；桌面 package/lock 版本与产品一致；后端和桌面 .NET 工程由根构建属性读取产品版本。源码版本不自动证明旧安装包已包含这些构建信息。

### PostgreSQL OAuth 链

源目录为 [Persistence/OAuthMigrations](../../backend/src/OobManagement.Infrastructure/Persistence/OAuthMigrations)。唯一迁移为 `20261102130635_AddMcpOAuthStorage`，创建 `OpenIddictApplications`、`OpenIddictAuthorizations`、`OpenIddictScopes`、`OpenIddictTokens`，由独立上下文与 `__McpOAuthMigrationsHistory` 维护；不能只核对业务历史就认定已完成。

源目录为 [Desktop.Storage/Persistence/Migrations](../../desktop/backend/OobManagement.Desktop.Storage/Persistence/Migrations)。与服务端共用业务实体，却拥有不同初始迁移与 Provider 语义，不能应用 PostgreSQL 迁移。

| --- | --- | --- |
| 1 | `20261101111729_InitialDesktopSqlite` | 九张基础业务表，包含当时用户/设备权限及异常记录；时间为 UTC 微秒 INTEGER，JSON 为 TEXT |

## 从已有安装对齐

本版没有一个能代表所有既有安装的旧产品版本号。先按[升级步骤](README.md#已有系统升级步骤)以实际应用身份读取每条适用链的完整 MigrationId、schema/SearchPath 和引擎状态，与台账逐条比较。已经完全一致的环境不重复初始化；更早且历史为目标链合法前缀的环境，只能在单独明确目标/动作授权和备份后应用缺失增量。未知/缺口历史、对象与历史不匹配先停止核对，不补写历史或重建库。

服务端按业务 → OAuth 顺序串行迁移；普通启动不自动处理，`--initialize` 还含管理员/设备 Bootstrap，不能当作已有库纯迁移入口。本次没有新增服务端自动升级执行器。桌面使用现有维护页面确认管理员密码、先一致性备份再应用 SQLite 链，未就绪前不启动采集；备份须配套密钥/配置和必要文件。

默认短维护停写，停止旧应用及采集、报表调度；本版不承诺零停机。优先证明结构与数据兼容后才程序回退，否则恢复配套升级前快照与旧制品，不默认执行 `Down`。风扇历史归并明确不支持反向恢复；权限迁移还须核对回填和旧会话失效，不只比行数。

PostgreSQL 17/TimescaleDB 2.31.0 是当前仓库固定的基础设施输入，本次未查询实际环境也未升级；实际引擎、扩展、schema 与备份可恢复性仍按目标核验。SQLite/OpenIddict 版本以锁定依赖及对应运行产物核对，不能用产品 `1.0.0` 替代引擎版本。

## 交付与验证边界

本基线在整理时运行静态版本/摘要、文档、前端门禁、后端/桌面构建及驱动等非数据库检查；没有重跑完整数据库门禁，结果以仓库检查链的如实输出为准。现有 PostgreSQL 集成测试会创建隔离 schema，桌面测试会建立/迁移文件库，未执行不能记为通过。

空库安装、旧版带数据升级、重复/失败恢复、备份还原、真实浏览器/各平台安装、外部 MCP/SMTP 和真机操作没有因本基线而重新验收。实际发布前需在目标环境补齐适用验证；人工验收与非作者评审不由本记录代替。

历史镜像标签与交付记录不构成本版源码基线的唯一标识；本仓库不包含构建、推送或部署记录。实际发布时另附不可变制品摘要与验收证据，不修改旧版迁移台账。
