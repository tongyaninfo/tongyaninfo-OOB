# 后端接口文档

全部后端接口文档统一按 `docs/api/<模块>/` 归档，前端开发、联调和接口评审从这里查阅。本入口只导航模块，不重复维护接口字段或生成产物。

## 目录与模块登记

以下是目录格式，不代表已有对应服务或可运行命令：

```text
docs/api/
├── README.md                 # 说明及模块索引
└── <模块>/
    ├── README.md             # 职责、接口索引、来源和使用说明
    ├── routes.json           # 实际注册路由覆盖清单
    ├── schemas.json          # DTO序列化与校验的JSON Schema合同
    ├── manifest.json         # 源文件与产物摘要（工具支持时）
    ├── endpoints.md          # 接口语义、示例及错误处理
    └── schemas.md            # 模型字段、校验与序列化说明
```

`<模块>` 使用确认后的实际名称，不按成员、设备或任务编号拆分。模块入口注明提供服务、代码来源、版本、生成和消费入口；跨服务同名模块先明确归属，避免路由或操作标识歧义。受维护子目录补齐大写 `README.md`。

当前采用模块为 [oob](oob/README.md)：认证、账号设置、服务器、硬件、采样、历史、电源、邮件与 MCP 管理，来源为实际 .NET 后端 MVC/端点及 JSON 序列化元数据。PC 在自身 `src/services/oob/generated.ts` 消费同源生成类型。Swagger/OpenAPI 服务及正式生成链已退役；其他来源合同留存取证，不作为本期服务或生成门禁。

[MCP 接入](mcp/README.md)说明独立远程协议、OAuth、工具白名单、限额与日志。MCP/OAuth 使用原生响应；管理 REST 类型仍归属 oob 合同，不另建第二套业务 DTO。

## 生成来源与更新闭环

- 后端提供给调用方的所有接口均须文档化，包括业务、管理、内部、回调、上传和下载；方法与路径以实际注册结果核验，不能只覆盖 JSON 成功响应。
- 后端 DTO、路由、显式校验及序列化定义是权威源，由此离线生成路由清单、JSON Schema 与说明。生成部分注明固定工具版本、来源摘要和唯一输出；人工业务语义单独维护，不靠手改生成字段建立另一套合同。
- 正式合同统一维护在 `docs/api/<模块>/`；客户端和 TypeScript 类型按实际模块生成到已确认的唯一位置，经正式公开入口消费。shared 不维护另一份主档，跨端模型保持同源，模块引用须可解析。MCP 工具 Schema 独立维护，不能代替完整 REST 合同。
- 每次新增、调整、废弃或移除接口，在同一项可审查变更中更新后端源、文档、索引、生成客户端及消费方验证，记录兼容影响、适用版本和迁移说明。未同步不能标记完成；文件删除仍须遵守当前用户授权边界。
- 路由覆盖、字段与响应一致性、生成漂移均应检查；工具和命令以[当前合同工具](../../scripts/README.md#合同链)及真实清单为准。本地检查通过不代表远端 CI 已配置。

## 每份接口文档的内容

| 内容 | 要求 |
| --- | --- |
| 定位与版本 | 模块、提供服务、用途、方法、路径、接口标识、来源和适用版本 |
| 身份与权限 | 认证、角色、数据范围、前置状态；限制接口也要文档化 |
| 请求 | 路径、查询、头、请求体或文件参数，类型、必填、可空、枚举、默认值和示例 |
| 响应 | 成功与失败结构、统一 ApiResult、HTTP 状态、业务码与字段语义；文件和流按真实协议说明 |
| 通用语义 | 长 ID 字符串、日期格式与时区、分页、排序、筛选及限额 |
| 行为边界 | 状态变化、副作用、幂等、并发、超时、重试和结果核对；不适用时写明依据 |
| 变更与验证 | 原因、兼容性、消费端影响、来源摘要、实际结果；区分未实现与未验证 |

示例遵守正式合同，不编造业务规则，不把历史环境配置写成公共默认值。已有信息仅在对应维护源更新，设计和变更记录通过相对链接引用。

## 前端与客户端消费

本期 PC，以及未来实际建立的 H5 消费方，开发前先读对应模块文档，核对方法、路径、权限、参数、响应、错误码和版本，再使用正式生成的客户端和类型。各消费工程锁定工具、版本、来源摘要、唯一输出与公开入口；发布制品时同步记录版本和摘要。

文档缺失、过期或与实现冲突时，记录具体差异，由后端核对并同步修正文档及生成产物后完成依赖该接口的联调。不凭历史页面、Mock 或猜测补接口，不在前端手改生成类型掩盖差异；不依赖该接口的工作可以继续。
