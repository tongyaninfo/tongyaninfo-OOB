# 桌面 SQLite 集成测试

本项目复用正式 API、业务服务、SQLite 适配和迁移。每个夹具在系统临时目录下创建独占文件库，显式初始化迁移，结束后保留库和缓冲文件。没有 PostgreSQL 运行依赖，不读取现有私密配置，不删除任何文件。

```sh
dotnet test desktop/tests/OobManagement.Desktop.Tests/OobManagement.Desktop.Tests.csproj
```

覆盖真实登录、防伪与权限、长 ID、设置隔离、UTC 微秒时间筛选、历史聚合与缺测、Unicode 账号唯一性、独立线程并发撤权、未知电源意图幂等、异常补入及在线备份。确定性函数回归覆盖 EF 连接重开；PostgreSQL 兼容用例只比较既有迁移快照与设计时模型，不打开连接。

业务夹具移除后台任务，所有带外驱动替换为无网络能力的内存实现。真实桌面宿主用例通过标准输入启动独占子进程，明确禁用采集、不添加任何设备，覆盖本次启动门禁、显式初始化、管理员登录与备份、重启恢复、LAN镜像供给边界。归档测试覆盖正常恢复、拒绝覆盖、路径越界及重复项；结束时仅停止本对象启动的进程并保留数据目录。

LAN回归使用本机真实非loopback IPv4验证Host允许列表；环境必须具有可绑定的活动IPv4接口。待升级回归在独占旧结构夹具中模拟缺少认证列，并逐请求携带此前签发的有效Cookie，确认设置、状态及防伪端点可达。Unix符号链接回归验证恢复不会沿既有`data`链接写到目标目录外；Windows仅跳过该权限语义用例。

备份回归还覆盖独占介质锁不会阻止备份、进程锁不进入归档、目录末尾分隔符、异常重放游标不被备份或从旧归档恢复。游标用例制造数据库快照未包含但缓冲已标记处理的日志，恢复后必须按原ID补入，避免日志遗漏。

电源用例只增加替身计数，不能视为真机验收；桌面安装、浏览器和跨平台打包由各自验证入口覆盖。
