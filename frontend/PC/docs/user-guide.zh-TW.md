## 快速開始

1. 使用管理員分配的系統帳號和密碼登入，預設進入「執行總覽」。系統帳號與設備帶外帳號分別維護。
2. 有「伺服器管理」權限時，進入「伺服器管理」新增設備，填寫帶外位址、帳號及採樣設定並保存。
3. 使用連接測試檢查設備存取，再進入詳情重新整理硬體庫存、查看即時採樣與歷史。
4. 需要遠端畫面時進入「虛擬控制台」，選擇伺服器並點擊「連接」。開啟頁面或選擇設備不會自動連接控制台。

一般帳號預設可查看總覽、伺服器列表及詳情。使用者管理、虛擬控制台、伺服器管理、電源操作分別授權；郵件和異常資訊僅系統管理員可見。若入口或按鈕缺少，請聯絡管理員確認權限。

## 執行總覽與歷史

首頁依序展示 CPU 溫度、整機功率、風扇轉速、陣列卡溫度、進排氣溫度。每張卡的左右箭頭獨立切換總體與單台伺服器；頁面層級箭頭可切換整頁範圍。游標停留或聚焦數字可查看設備明細。

- 預設趨勢為最近15分鐘。總體 CPU、進氣與排氣顯示最高、平均、最低；單機保留各 CPU 和溫度探頭的獨立曲線，進氣為虛線、排氣為實線。
- 風扇按 RPM 或百分比顯示，切換單位後查看對應曲線與明細。設備缺少某種單位時不會用另一單位換算。
- 點擊卡片右上角歷史搜尋圖示，選擇過去一天、一週、一個月，或輸入上海時間範圍後明確查詢。查詢跟隨目前卡片及伺服器範圍，單次最多366天，僅使用已入庫資料。
- 點擊看板右上角全螢幕圖示進入全螢幕，仍可切換、查看明細和歷史；按 Esc 或點擊退出恢復。

WebSocket 狀態表示即時推送連接。斷線、採樣失敗或讀數過期會留下缺口；重新連接只接收後續採樣，不自動補齊缺少資料。空值、不支援和過期讀數不等於0。

## 伺服器管理

點擊「新增」，填寫名稱，選擇 HP / iLO4 或 DELL / iDRAC 8，輸入帶外管理位址、設備帳號和密碼。採樣間隔為1–86400秒，預設30秒；啟用後由系統按設定採集。

新增設備預設勾選「忽略 HTTPS 憑證錯誤」，應根據設備憑證情況選擇；設定憑證指紋後仍須符合該指紋。編輯時密碼留空可保留原密碼；更換位址、設備帳號等需要重新確認憑證的欄位時，按頁面提示重新輸入。單獨調整憑證策略不要求重輸原密碼。

連接測試用於確認設備存取；保存與連接測試是不同操作。進入伺服器詳情可編輯設定、重新整理硬體庫存或手動採樣，這些操作均需要「伺服器管理」權限。採樣和庫存讀取不發送開關機命令。

## 設定匯入匯出

- **匯出設定**：匯出全部伺服器設定，不受目前搜尋和分頁影響。檔案包含設備帳號與登入密碼，設定8–128字元的檔案密碼後產生加密檔案，請分別妥善保管檔案和密碼。
- **匯入設定**：選擇加密 JSON 檔案（最大4 MiB），輸入檔案密碼並確認。按帶外位址與控制器類型識別設備：相同設定略過、不同設定覆寫、未找到的新增；檔案中未包含的伺服器保留。
- 覆寫設定保留原伺服器識別碼及監控歷史，完成後頁面顯示新增、覆寫、略過數量。結果未知時先重新整理列表核對，再決定下一步，系統不自動重複匯入。

## 伺服器詳情

點擊伺服器進入詳情，頂部查看型號、序號、帶外位址、韌體、採樣時間和連接提示。

| 區域 | 用法 |
| --- | --- |
| 硬體庫存 | 查看 CPU、記憶體、電池、電源設備和控制器下掛磁碟；有權限時可重新整理庫存 |
| 即時資料 | 查看設備提供的功率、溫度、風扇等指標；有權限時可手動採樣 |
| 歷史資料 | 選擇指標和時間範圍查詢，按單位查看曲線與彙總 |
| 電源操作 | 按目前權限、設備能力和全域開關展示可執行動作及操作記錄 |

讀數保留單位、來源、採樣時間及不支援/缺測狀態。陣列卡溫度只顯示明確的陣列卡感測器，不使用硬碟或電池溫度代替。預設時間按 Asia/Shanghai（上海時間）展示。

## UID與電源操作

UID 用於定位伺服器，需「伺服器管理」權限。根據設備能力選擇常亮、閃爍或關閉，點擊即向設備發送，不再輸入伺服器名稱；操作後以回讀狀態為準。

電源操作需獨立的「電源操作」權限，且部署管理員已開啟真實電源控制。頁面先讀取目前能力；選擇動作後輸入完全符合的伺服器名稱並確認。

- 開機、短按電源鍵、長按強制關機、優雅關機或重新啟動等選項以設備實際支援為準。強制動作可能中斷執行中的系統，請先確認業務狀態。
- 「設備已接受」不代表動作已完成。出現結果未知或待核對時，查詢原操作記錄，不要再次建立同一動作。
- 原操作人的人工核對需填寫實際結果及依據，只更新操作記錄，不向設備補發命令。

頁面掛載、重新整理、背景採樣均不會發送電源動作。

## 虛擬控制台與虛擬媒體

選擇伺服器後點擊「連接」，可同時開啟最多4個一般標籤或懸浮視窗。韌體或廠商橋接尚未支援時會顯示不可用提示，無法僅靠重新整理獲得設備未提供的能力。

開啟「鍵鼠輸入」後點擊畫面接管輸入；點擊其他區域或按 Ctrl+Alt 釋放按鍵與捕獲，輸入開關保持開啟，再點擊畫面可繼續。螢幕鍵盤可發送 Esc、功能鍵和組合鍵，不支援中文輸入法或文字貼上。

控制台全螢幕時 Esc 會發送至遠端，按 Ctrl+Alt 解鎖；支援鍵盤鎖定的 HTTPS 瀏覽器可獲得完整輸入捕獲，其餘環境可能採用頁面全螢幕並提示限制。可使用頁面退出按鈕；瀏覽器保留長按 Esc 應急退出能力。

點擊全螢幕圖示下的提取按鈕可將畫面放入頁面內懸浮視窗，支援拖動、縮放、最小化和放回頁面；切換系統選單保留同一連接。關閉標籤、重新整理或關閉瀏覽器頁面會結束會話，登出帳號或撤銷控制台權限也會清理會話。

虛擬媒體在抽屜中操作，按設備能力提供本機映像、平台映像庫或設備可存取的映像 URL：

- 本機映射選擇非空 ISO（最大16 GiB），無須先完整上傳；整個使用期間保持目前瀏覽器頁面及會話連接。
- 平台映像庫支援 ISO 和1.44 MB IMG，上傳檔案最大16 GiB；平台位址及設備存取條件未就緒時不可掛載。
- 掛載或卸載前選擇虛擬設備並輸入伺服器名稱確認。操作只插入/移除媒體，不改變啟動順序、不重新啟動伺服器。
- 關閉抽屜不會卸載媒體。URL/映像庫掛載獨立於控制台，關閉控制台標籤也不會自動拔盤；本機映射依賴瀏覽器會話。
- 結果未知時查詢原媒體操作。原操作人只有核實確實未執行後才能填寫依據，人工確認未執行；此操作不重發掛載或卸載命令。

會話流量統計平台可觀測的控制台與媒體載荷，映像讀取流量單列，均不代表伺服器網卡總流量。

## 使用者與帳戶

有「使用者管理」權限時可新增/編輯使用者、啟用/停用、邏輯刪除、獨立重設密碼，並分別勾選四項權限。伺服器管理包括設備設定、連接測試、庫存重新整理、手動採樣和 UID；電源操作包括電源動作、操作記錄與結果核對。

系統管理員標誌不代替四項權限。一般使用者管理員不能修改系統管理員帳號。未刪除帳號（含停用）去除首尾空格後不區分大小寫唯一；已刪除帳號可重新使用。

點擊右上角頭像的「修改密碼」，輸入原密碼、新密碼及確認值；密碼長度8–128字元。帳號、密碼、啟停狀態或權限變化會使舊會話失效。頭像中的帳戶設定頁仍有範本資料/安全演示，相關保存尚未接入，請使用正式「修改密碼」入口。

## 郵件與執行報表

系統管理員進入「郵件」，使用「寄件記錄」「信箱設定」「執行報表」三個頁籤。

1. 在信箱設定填寫 SMTP 伺服器、寄件信箱、授權碼/密碼；進階設定預設465連接埠和 SSL/TLS，也可按信箱服務要求選擇 STARTTLS（通常587連接埠）。登入帳號留空時使用寄件信箱，編輯密碼留空保留已保存值。
2. 點擊「保存設定」。保存不連接、不發信；保存後可分別點擊「檢測連接」或「發送測試郵件」。修改未保存時先保存。
3. 在寄件記錄點擊「發送郵件」，填寫單一收件信箱、主旨和內文並確認；可篩選記錄、開啟詳情查看結果。

「郵件伺服器已受理」不代表收件人已收到。結果未知時查詢本次原請求；只有頁面明確允許時才按原請求重試。系統只記錄本系統寄件，不提供收信功能。

執行報表可分別設定日報、週報、月報的收件人及上海時間發送點，預設關閉，保存計畫不會立即發信。統計上一完整自然日、自然週（週一至週日）或自然月；每月可選1–31日，短月取最後一天。服務離線恢復只處理最近到期的一期，已有記錄不會自動重發。

歷史執行分析輸入上海時間起止範圍，最多366天，包含起點、不含終點；點擊「產生預覽」或「下載 HTML」只讀取已入庫資料，不發郵件。報表中的採集成功率表示採集結果，不等同伺服器線上率。

## 主題與語言

從右上角頭像的主題設定或齒輪開啟外觀設定，在「整體風格設定」選擇淺色、深色或自動。自動模式跟隨作業系統的淺深色變化；手動模式保持所選風格。設定按目前帳號保存，重新登入後恢復。

右上角語言入口支援簡體中文、繁體中文和 English，使用文件隨語言切換。右上角書本圖示可隨時回到本文。

## 異常資訊與排查

系統管理員進入「異常資訊」，可篩選系統異常、設備讀取失敗或前端異常，開啟脫敏詳情並複製給維護人員；一般業務驗證失敗不作為系統異常記錄。

| 現象 | 建議檢查 |
| --- | --- |
| 總覽沒有讀數或出現缺口 | 檢查設備是否啟用、最近採樣時間、WebSocket狀態和設備警告；有權限時測試連接或手動採樣 |
| 連接失敗 | 檢查帶外位址、設備帳號、網路、憑證策略及指紋；以頁面錯誤說明為準 |
| 控制台暫不可用 | 查看韌體/設備能力提示、會話狀態及瀏覽器限制，不反覆建立未知結果的連接 |
| 電源按鈕不可用 | 檢查電源權限、全域開關、即時能力及是否有待核對操作 |
| 郵件結果未知 | 查詢原請求及寄件詳情，並核對信箱伺服器端結果，避免重複發送 |
| 需要協助 | 提供發生時間、伺服器名稱、操作步驟、錯誤碼或脫敏異常摘要，不發送設備密碼或檔案密碼 |
