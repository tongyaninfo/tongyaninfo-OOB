## 快速开始

1. 使用管理员分配的系统账号和密码登录，默认进入“运行总览”。系统账号与设备带外账号分别维护。
2. 有“服务器管理”权限时，进入“服务器管理”新增设备，填写带外地址、账号及采样设置并保存。
3. 使用连接测试检查设备访问，再进入详情刷新硬件库存、查看实时采样与历史。
4. 需要远程画面时进入“虚拟控制台”，选择服务器并点击“连接”。打开页面或选择设备不会自动连接控制台。

普通账号默认可查看总览、服务器列表及详情。用户管理、虚拟控制台、服务器管理、电源操作分别授权；邮件和异常信息仅系统管理员可见。若入口或按钮缺失，请联系管理员确认权限。

## 运行总览与历史

首页依次展示 CPU 温度、整机功率、风扇转速、阵列卡温度、进排气温度。每张卡的左右箭头独立切换总体与单台服务器；页面级箭头可切换整页范围。悬浮或聚焦数字可查看设备明细。

- 默认趋势为最近15分钟。总体 CPU、进气与排气显示最高、平均、最低；单机保留各 CPU 和温度探头的独立曲线，进气为虚线、排气为实线。
- 风扇按 RPM 或百分比显示，切换单位后查看对应曲线与明细。设备缺少某种单位时不会用另一单位换算。
- 点击卡片右上角历史搜索图标，选择过去一天、一周、一个月，或输入上海时间范围后明确查询。查询跟随当前卡片及服务器范围，单次最多366天，仅使用已入库数据。
- 点击看板右上角全屏图标进入全屏，仍可切换、查看明细和历史；按 Esc 或点击退出恢复。

WebSocket 状态表示实时推送连接。断线、采样失败或读数过期会留下缺口；重新连接只接收后续采样，不自动补齐缺失数据。空值、不支持和过期读数不等于0。

## 服务器管理

点击“新增”，填写名称，选择 HP / iLO4 或 DELL / iDRAC 8，输入带外管理地址、设备账号和密码。采样间隔为1–86400秒，默认30秒；启用后由系统按配置采集。

新增设备默认勾选“忽略 HTTPS 证书错误”，应根据设备证书情况选择；配置证书指纹后仍须匹配该指纹。编辑时密码留空可保留原密码；更换地址、设备账号等需要重新确认凭据的字段时，按页面提示重新输入。单独调整证书策略不要求重输原密码。

连接测试用于确认设备访问；保存与连接测试是不同操作。进入服务器详情可编辑配置、刷新硬件库存或手动采样，这些操作均需要“服务器管理”权限。采样和库存读取不发送开关机命令。

## 配置导入导出

- **导出配置**：导出全部服务器配置，不受当前搜索和分页影响。文件包含设备账号与登录密码，设置8–128字符的文件密码后生成加密文件，请分别妥善保管文件和密码。
- **导入配置**：选择加密 JSON 文件（最大4 MiB），输入文件密码并确认。按带外地址与控制器类型识别设备：相同配置跳过、不同配置覆盖、未找到的新增；文件中未包含的服务器保留。
- 覆盖配置保留原服务器标识及监控历史，完成后页面显示新增、覆盖、跳过数量。结果未知时先刷新列表核对，再决定下一步，系统不自动重复导入。

## 服务器详情

点击服务器进入详情，顶部查看型号、序列号、带外地址、固件、采样时间和连接提示。

| 区域 | 用法 |
| --- | --- |
| 硬件库存 | 查看 CPU、内存、电池、电源设备和控制器下挂磁盘；有权限时可刷新库存 |
| 实时数据 | 查看设备提供的功率、温度、风扇等指标；有权限时可手动采样 |
| 历史数据 | 选择指标和时间范围查询，按单位查看曲线与汇总 |
| 电源操作 | 按当前权限、设备能力和全局开关展示可执行动作及操作记录 |

读数保留单位、来源、采样时间及不支持/缺测状态。阵列卡温度只显示明确的阵列卡传感器，不使用硬盘或电池温度代替。默认时间按 Asia/Shanghai（上海时间）展示。

## UID与电源操作

UID 用于定位服务器，需“服务器管理”权限。根据设备能力选择常亮、闪烁或关闭，点击即向设备发送，不再输入服务器名称；操作后以回读状态为准。

电源操作需独立的“电源操作”权限，且部署管理员已开启真实电源控制。页面先读取当前能力；选择动作后输入完全匹配的服务器名称并确认。

- 开机、短按电源键、长按强制关机、优雅关机或重启等选项以设备实际支持为准。强制动作可能中断运行中的系统，请先确认业务状态。
- “设备已接受”不代表动作已完成。出现结果未知或待核对时，查询原操作记录，不要再次创建同一动作。
- 原操作人的人工核对需填写实际结果及依据，只更新操作记录，不向设备补发命令。

页面挂载、刷新、后台采样均不会发送电源动作。

## 虚拟控制台与虚拟介质

选择服务器后点击“连接”，可同时打开最多4个普通标签或悬浮窗口。固件或厂商桥接尚未支持时会显示不可用提示，无法仅靠刷新获得设备未提供的能力。

开启“键鼠输入”后点击画面接管输入；点击其他区域或按 Ctrl+Alt 释放按键与捕获，输入开关保持开启，再点击画面可继续。屏幕键盘可发送 Esc、功能键和组合键，不支持中文输入法或文本粘贴。

控制台全屏时 Esc 会发送至远端，按 Ctrl+Alt 解锁；支持键盘锁定的 HTTPS 浏览器可获得完整输入捕获，其余环境可能采用页面全屏并提示限制。可使用页面退出按钮；浏览器保留长按 Esc 应急退出能力。

点击全屏图标下的提取按钮可将画面放入页面内悬浮窗，支持拖动、缩放、最小化和放回页面；切换系统菜单保留同一连接。关闭标签、刷新或关闭浏览器页面会结束会话，退出账号或撤销控制台权限也会清理会话。

虚拟介质在抽屉中操作，按设备能力提供本机镜像、平台镜像库或设备可访问的镜像 URL：

- 本机映射选择非空 ISO（最大16 GiB），无需先完整上传；整个使用期间保持当前浏览器页面及会话连接。
- 平台镜像库支持 ISO 和1.44 MB IMG，上传文件最大16 GiB；平台地址及设备访问条件未就绪时不可挂载。
- 挂载或卸载前选择虚拟设备并输入服务器名称确认。操作只插入/移除介质，不改变启动顺序、不重启服务器。
- 关闭抽屉不会卸载介质。URL/镜像库挂载独立于控制台，关闭控制台标签也不会自动拔盘；本机映射依赖浏览器会话。
- 结果未知时查询原介质操作。原操作人只有核实确实未执行后才能填写依据，人工确认未执行；此操作不重发挂载或卸载命令。

会话流量统计平台可观测的控制台与介质载荷，镜像读取流量单列，均不代表服务器网卡总流量。

## 用户与账户

有“用户管理”权限时可新增/编辑用户、启用/停用、逻辑删除、独立重设密码，并分别勾选四项权限。服务器管理包括设备配置、连接测试、库存刷新、手动采样和 UID；电源操作包括电源动作、操作记录与结果核对。

系统管理员标志不代替四项权限。普通用户管理员不能修改系统管理员账号。未删除账号（含停用）去除首尾空格后不区分大小写唯一；已删除账号可重新使用。

点击右上角头像的“修改密码”，输入原密码、新密码及确认值；密码长度8–128字符。账号、密码、启停状态或权限变化会使旧会话失效。头像中的账户设置页仍有模板资料/安全演示，相关保存尚未接入，请使用正式“修改密码”入口。

## 邮件与运行报表

系统管理员进入“邮件”，使用“发件记录”“邮箱配置”“运行报表”三个页签。

1. 在邮箱配置填写 SMTP 服务器、发件邮箱、授权码/密码；高级设置默认465端口和 SSL/TLS，也可按邮箱服务要求选择 STARTTLS（通常587端口）。登录账号留空时使用发件邮箱，编辑密码留空保留已保存值。
2. 点击“保存配置”。保存不连接、不发信；保存后可分别点击“检测连接”或“发送测试邮件”。修改未保存时先保存。
3. 在发件记录点击“发送邮件”，填写单个收件邮箱、主题和正文并确认；可筛选记录、打开详情查看结果。

“邮件服务器已受理”不代表收件人已收到。结果未知时查询本次原请求；只有页面明确允许时才按原请求重试。系统只记录本系统发件，不提供收信功能。

运行报表可分别配置日报、周报、月报的收件人及上海时间发送点，默认关闭，保存计划不会立即发信。统计上一完整自然日、自然周（周一至周日）或自然月；每月可选1–31日，短月取最后一天。服务离线恢复只处理最近到期的一期，已有记录不会自动重发。

历史运行分析输入上海时间起止范围，最多366天，包含起点、不含终点；点击“生成预览”或“下载 HTML”只读取已入库数据，不发邮件。报表中的采集成功率表示采集结果，不等同服务器在线率。

## 主题与语言

从右上角头像的主题设置或齿轮打开外观设置，在“整体风格设置”选择浅色、深色或自动。自动模式跟随操作系统的浅深色变化；手动模式保持所选风格。设置按当前账号保存，重新登录后恢复。

右上角语言入口支持简体中文、繁體中文和 English，使用文档随语言切换。右上角书本图标可随时回到本文。

## 异常信息与排查

系统管理员进入“异常信息”，可筛选系统异常、设备读取失败或前端异常，打开脱敏详情并复制给维护人员；普通业务校验失败不作为系统异常记录。

| 现象 | 建议检查 |
| --- | --- |
| 总览没有读数或出现缺口 | 检查设备是否启用、最近采样时间、WebSocket状态和设备警告；有权限时测试连接或手动采样 |
| 连接失败 | 检查带外地址、设备账号、网络、证书策略及指纹；以页面错误说明为准 |
| 控制台暂不可用 | 查看固件/设备能力提示、会话状态及浏览器限制，不反复创建未知结果的连接 |
| 电源按钮不可用 | 检查电源权限、全局开关、实时能力及是否有待核对操作 |
| 邮件结果未知 | 查询原请求及发件详情，并核对邮箱服务端结果，避免重复发送 |
| 需要协助 | 提供发生时间、服务器名称、操作步骤、错误码或脱敏异常摘要，不发送设备密码或文件密码 |
